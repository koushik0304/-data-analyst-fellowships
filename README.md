# Data Analyst Fellowship — Assignments

Assignments completed as part of the Data Analyst Fellowship (Unified Mentor) course.

## Contents

- `Exploratory_Data_Analysis_Assignment.ipynb` — EDA on a Kaggle cars dataset (cleaning, outlier detection via IQR, univariate/bivariate/multivariate visualizations, correlation heatmap)
- `Cars_data_.csv` — dataset used in the EDA assignment
- `Pandas_Advanced_Assignment.ipynb` — advanced Pandas exercises
- `Numpy_Advanced_Assignment.ipynb` — advanced NumPy exercises
- `Python_Basics_Assignment.ipynb` — Python fundamentals exercises
- `Python_Data_Structure_Assignment.ipynb` — Python data structures exercises

## Requirements

```
pandas
numpy
seaborn
matplotlib
scipy
```
